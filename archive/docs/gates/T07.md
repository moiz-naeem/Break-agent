- **MCP startup-failure rule (spike risk 2):**
  - **Trial error:** the episode log has **zero** budgeted tool calls (entries refused with
    `R-SHIFT-ENDED` don't count) **and** a line under `/logs/agent` names our server and reports a failure.
    - A line names our server if it contains `key=railway` or `server=railway`, or both `mcp` and
      `railway`.
    - A failure is a whole-word match of unavailable, failed, failure, error, refused, timeout, timed out
      or unreachable.
    - The verifier then prints `INFRA: agent started without MCP tools ...`, exits 1 and writes no reward.
  - **Scored normally:**
    - zero calls with no such line (no agent logs, as with `nop`; a healthy MCP line; the probe's
      `No module named 'railway'`; another server's failure; the prompt) → 0;
    - any episode with ≥ 1 call, whatever the agent log says.
