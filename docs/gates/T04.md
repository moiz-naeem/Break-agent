## Update 2026-11-14: missing tests and a generator bug (Claude, Opus 5.5)

- **Bug found and fixed:** `railway/gen/generator.py` wrote stop `arr`/`dep` **relative to the train's entry tick**. The simulator, the cost code and the mini3 fixture all treat them as absolute ticks.
  - Example: T2 seed 7's E1 entered at t=83 with S1 scheduled at t=4. Every generated train was late from the moment it entered, or held to a timetable already in the past, so the cost signal was meaningless.
  - The old property test encoded the same mistake (`stops[-1].arr + entry_tick <= shift - 15`), so it could not catch it.
  - **Fix:** stops are offset by the entry tick. Rotation pairing and the breakdown window read the absolute arrival. Crew sizing uses `run_length(train) = last arr - entry`, and the dead `run_lengths` parameter is gone.
  - **Red → green:** the corrected T04-18 per-stop free-run property failed on every preset before the fix and passes after it.
  - **Regression test `test_T04_18b_direct_run_is_on_time`:** it fails on the old output (`S1 sched 8, actual 55`) and passes on the new one.
