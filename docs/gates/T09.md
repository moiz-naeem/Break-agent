- **Deviations from PRD (and why):**
  - **Stats adapter.** T08 §2.8 defines the statistics but not the Python names. `railway/eval/_stats.py` is the single adapter and assumes `stats.summarize(rows)` (see Residual risks).

  - **Tool-usability rate.** It is Σ(invalid_calls + format_errors) / Σtool_calls over the small model's ok rows. Harbor rows have no `format_errors`, so they count as 0.
